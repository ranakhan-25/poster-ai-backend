# PosterAI Backend

Backend API for **PosterAI**, an AI-powered political and event poster generation platform.

The backend provides authentication, poster management, template management, AI-assisted generation, image storage, and secure user-specific poster history.

---

## Features

* JWT-based authentication
* Access token + refresh token authentication
* HTTP-only authentication cookies
* User registration and login
* Automatic access-token refresh
* Protected API routes
* MongoDB database with Mongoose
* Poster creation and management
* Poster regeneration
* Poster deletion
* User poster history
* Poster templates
* Gemini AI integration
* Cloudinary image storage
* Image upload with Multer
* Zod environment/config validation
* TypeScript
* Express.js
* Centralized error handling
* Production-ready build with TypeScript

---
